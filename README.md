# Slide Memo

## 1. 슬라이드 메모 소개

화면 가장자리(왼쪽 또는 오른쪽)에 세로 탭으로 붙어 있다가, 누르면 펼쳐지는 Windows 메모장이에요.
다른 앱을 쓰면서 바로 적고 다시 숨길 수 있어요.

- 항상 다른 앱 위에 보여요
- 시스템 트레이나 작업 표시줄에서 열고 닫아요
- 메모마다 종이 톤 색 띠가 있는 세로 탭
- 모든 데이터는 내 컴퓨터의 SQLite에 저장돼요 (외부 서버 없음)

---

## 2. 주요 기능

### 메모 작성·관리

- 메모 만들기, 고치기, 지우기, 검색, 정렬 (수정일 / 만든 날짜 / 제목)
- 검색한 글자는 본문에서 강조돼요
- 메모 고정 (탭 우클릭 또는 위 줄의 고정 단추) — 어떤 정렬에서도 맨 위에 있고, 고정한 탭에는 책갈피가 달려요
- 휴지통 — 30일이 지나면 저절로 완전히 지워지고, 한 번에 비울 수도 있어요
- 자동 저장 (입력을 멈추고 0.6초 뒤)
- 이전 버전 되돌리기 (Ctrl+Alt+Z)
- 내보내기 — 문서(.odt)·마크다운(.md)·텍스트(.txt) (Ctrl+E)

### 서식

- 굵게 / 기울임 / 밑줄 / 취소선
- 글자색 10가지 + 직접 고르기
- 형광펜 5가지 + 지우기
- 글꼴·크기 (메모마다 다르게 정할 수 있어요)
- 정렬 (왼쪽 / 가운데 / 오른쪽)
- 글머리 목록 / 번호 목록
- 링크 넣기 (URL)
- 표 넣기 (행·열·머리글 선택)
- 날짜·시간 넣기 (메모장 형식, ISO, 한국식 등 5가지)
- 이미지 붙여넣기 (Ctrl+V)

### AI 기능 (선택, 본인 API 키 필요)

처음에는 꺼져 있어요. 설정 → AI 탭에서 켜고 API 키를 등록하면 쓸 수 있어요.

- 요약 — 고른 부분이나 메모 전체를 요약해요
- 번역 — 한국어와 영어를 알아서 바꿔요
- 맞춤법 교정 — 철자·문법·문장 부호를 고쳐요
- 제목 생성 — 본문을 보고 짧은 제목을 지어요
- 키워드 추출 — 키워드 5~10개를 본문 끝에 붙여요

지원 제공자:
- Anthropic Claude
- OpenAI (GPT)
- Google Gemini
- Ollama (로컬 모델, API 키 필요 없음)

### 음성 녹음 (선택)

OpenAI Whisper API로 말을 글로 바꿔요. 마이크 권한과 OpenAI 키가 필요해요.

- 서식바의 마이크 단추로 녹음을 시작하고 끝내요
- 끝내면 Whisper가 바로 변환해서 새 메모를 만들어요
- 최대 녹음 시간을 정할 수 있어요 (안전장치, 기본 5분)
- 녹음 파일을 메모에 붙여 둘 수도 있어요

### 사용자화

- 화면 모드 (시스템 설정 따르기 / 밝게 / 어둡게)
- 붙는 가장자리 (왼쪽 / 오른쪽)
- 작업 표시줄 표시 (트레이에만 / 작업 표시줄에만 / 둘 다)
- Windows를 켤 때 자동 실행
- 탭 너비 (24~100px), 탭 높이 (60~200px)
- 창 불투명도
- 창 폭·높이는 가장자리를 끌어서 바꿔요
- 위쪽 손잡이(점 6개)를 끌어 위아래로 옮겨요

## 3. 설치 및 실행

### A. 설치 파일로 설치 (권장, Windows)

`SlideMemo-Setup.exe`를 더블클릭하면 마법사 단계 없이 진행 막대만 보였다가 앱이 바로 실행돼요.

- 설치 위치: `%LOCALAPPDATA%\Programs\SlideMemo\` (관리자 권한 필요 없음)
- 시작 메뉴와 바탕화면 바로가기를 만들어요
- 제거: 설정 → 앱 → 설치된 앱 → "Slide Memo" → 제거
- 2.0.0으로 올리면 메모 색이 바뀌어서 1.x로 되돌릴 수 없어요. 되돌리려면 업데이트 때 만든 백업을 써요. (`~/.memo_slide/memos.db.bak`)

### B. 소스에서 실행 (개발자)

필요한 것: Python 3.12 이상, [uv](https://docs.astral.sh/uv/)

```bash
uv sync
uv run python src/main.py
```

### 처음 실행

화면 가장자리(기본: 오른쪽)에 세로 탭이 보이고, 메모가 없으면 빈 메모 1개를 만들어요.
사용법을 말풍선으로 안내할지 먼저 물어봐요.

데이터 폴더 `~/.memo_slide/`를 자동으로 만들어요 (`~` = `C:\Users\<사용자명>`).

## 4-1. AI 기능 사용 (선택)

AI 기능은 처음에 꺼져 있고, 쓰려면 본인 API 키가 필요해요.

### 키 발급 페이지

| 제공자 | 발급 페이지 | 비고 |
|---|---|---|
| Anthropic | https://console.anthropic.com/ | 유료 |
| OpenAI | https://platform.openai.com/api-keys | 유료 |
| Google Gemini | https://aistudio.google.com/apikey | 무료 등급 있음 |
| Ollama | https://ollama.com/ | 로컬 설치, 무료 |

### 키 등록 방법

1. 트레이 아이콘이나 바를 우클릭 → 설정 → "AI" 탭
2. "제공자"에서 쓸 서비스를 골라요
3. "API 키"를 입력하고 "키 확인하기"로 확인해요
4. "모델"을 골라요
5. "AI 기능 사용"을 체크하고 저장하기를 눌러요

키는 시스템의 `keyring` 보안 저장소에 저장되고, DB나 파일에 그대로 남지 않아요.

### 사용법

본문 아래 AI 단추 줄(요약하기 · 번역하기 · 맞춤법 고치기 · 제목 짓기 · 키워드 뽑기)이나 단축키(다음 장 참고)로 써요.
본문에서 글을 고르고 누르면 그 부분에만, 고르지 않고 누르면 메모 전체에 적용돼요.

## 4-2. 음성 녹음 기능 사용

### 미리 준비

1. Windows 설정 → 개인정보 및 보안 → 마이크 → "앱이 마이크에 액세스하도록 허용" 켜기
2. OpenAI API 키 (Whisper는 OpenAI 키를 써요)
3. 설정 → AI 탭 아래 "음성 녹음 (Whisper)":
   - "음성 녹음 기능 사용" 체크
   - "Whisper용 OpenAI API 키" 입력 후 확인 (주 AI 제공자가 OpenAI가 아니어도 Whisper용 OpenAI 키만 따로 등록할 수 있어요)
4. (선택) "녹음 파일을 메모에 첨부" 체크 / "최대 녹음 시간" 조절

### 사용법

1. 서식바의 마이크 단추를 눌러 녹음을 시작해요
2. 말해요
3. 마이크 단추를 다시 누르면 녹음이 끝나고 변환이 시작돼요
4. 변환 중 표시가 사라지면 변환된 글로 새 메모가 만들어져요

비용: Whisper API는 1분에 약 $0.006 (약 8원)이에요.

## 5. 사용 방법

### 기본 조작

| 동작 | 방법 |
|---|---|
| 펼치기 | 메모 탭 누르기 / 트레이 아이콘 누르기 |
| 접기 | Esc / 같은 메모 탭 다시 누르기 |
| 다른 메모로 바꾸기 | 다른 탭 누르기 |
| 새 메모 | 탭 아래 더하기 단추 / Ctrl+N |
| 휴지통 열기 | 새 메모 단추 아래 휴지통 단추 (지운 메모 수가 숫자로 보여요) |
| 잠깐 숨기기 | 맨 아래 » 단추 / Ctrl+Shift+Z — 남은 로고 단추를 누르면 다시 나와요 |
| 반대쪽 가장자리로 옮기기 | 트레이 아이콘이나 바를 우클릭 → "반대쪽 가장자리로 옮기기" |
| 창 폭 조절 | 본문 왼쪽·오른쪽 가장자리 끌기 (펼친 상태) |
| 창 높이 조절 | 본문 위·아래 가장자리 끌기 (펼친 상태) |
| 창 위아래로 옮기기 | 위쪽 손잡이 끌기 |

### 단축키

| 단축키 | 동작 |
|---|---|
| `Esc` | 접기 (AI 작업 중이면 AI 취소) |
| `Ctrl+N` | 새 메모 |
| `Ctrl+F` | 검색 칸으로 이동 |
| `Ctrl+S` | 바로 저장 (자동 저장은 0.6초 뒤) |
| `Ctrl+Shift+C` | 메모 본문 전체 복사 |
| `Ctrl+Shift+D` | 메모 지우기 — 평소: 휴지통으로 / 휴지통에서: 완전히 지우기 |
| `Delete` | 탭을 고른 뒤 누르면 휴지통으로 (본문을 쓰는 중에는 글자 지우기) |
| `Ctrl+Shift+Z` | 바 잠깐 숨기기 / 다시 보이기 (어디서나) |
| `Ctrl+Alt+Z` | 이전 버전 보기 |
| `Ctrl+E` | 내보내기 |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | 굵게 / 기울임 / 밑줄 |
| `Ctrl+K` | 링크 넣기 |
| `F5` | 메모장 형식 날짜 (`오후 3:24 2026-05-23`) |
| `Ctrl+;` | 오늘 날짜 (`2026-05-23`) |
| `Ctrl+Shift+;` | 지금 시각 (`15:24`) |
| `Ctrl+Alt+;` | ISO 형식 (`2026-05-23T15:24:00`) |
| `Ctrl+Shift+H` | 한국식 날짜 (`2026년 05월 23일 토요일`) |
| `Ctrl+Alt+S` | AI 요약 |
| `Ctrl+Alt+T` | AI 번역 |
| `Ctrl+Alt+P` | AI 맞춤법 교정 |
| `Ctrl+Alt+H` | AI 제목 생성 |
| `Ctrl+Alt+K` | AI 키워드 추출 |

### 메모 색

제목 옆 색 단추에서 종이 톤 8가지(회색·노랑·주황·분홍·보라·파랑·청록·초록)와 직접 만든 색(최근 6개)을 골라요.
직접 만들 때는 한 가지 색만 골라요(그라데이션은 없어요). 어두운 화면에서는 탭의 색 띠로 메모를 구분해요. 새 메모는 노랑이에요.

### 설정

트레이 아이콘이나 바를 우클릭 → 설정. 탭은 세 개예요.

- **일반** — 화면 모드, 붙는 위치, 작업 표시줄, 탭 너비·높이, 창 불투명도, 자동 실행, 사용법 다시 보기
- **AI** — 제공자, 키, 모델, 이번 달 사용량, 미리 보기, 음성 녹음
- **정보** — 버전, 저작권, 데이터 폴더 열기

## 6. 데이터 저장 위치

모두 사용자 홈 폴더 아래에 저장돼요 (`~` = `C:\Users\<사용자명>`).

| 경로 | 내용 |
|---|---|
| `~/.memo_slide/memos.db` | SQLite 메모 DB (제목, 본문 HTML, 색, 글꼴, 고정, 휴지통 상태, 만든·고친 시각) |
| `~/.memo_slide/memos.db.bak` | DB 구조를 바꾸거나 메모 색을 옮길 때 자동으로 만든 백업 (있을 때만) |
| `~/.memo_slide/images/img_*.png` | 메모에 붙여 넣은 이미지 |
| `~/.memo_slide/temp/recording_*.wav` | 녹음 임시 파일 (변환 뒤 지워요) |
| `~/.memo_slide/audio/recording_*.wav` | "녹음 파일 첨부"를 켰을 때 보관 |
| 시스템 keyring | API 키 (Windows 자격 증명 관리자) |

### 백업 방법

`~/.memo_slide/` 폴더를 통째로 복사하면 메모와 이미지가 모두 보존돼요. API 키는 시스템 keyring에 있어서 따로 백업해야 해요 (다시 설치하면 다시 등록).

## 7. 문제 해결

### "AI 기능을 먼저 켜 주세요" 같은 안내가 떠요

설정 → AI 탭 → "AI 기능 사용"이 꺼져 있어요. 켜고 키도 등록해 주세요.

### 마이크 단추가 동작하지 않아요

이 순서로 확인해 주세요.
1. 설정 → AI 탭 → "AI 기능 사용" 체크
2. 같은 탭 아래 "음성 녹음 (Whisper)" → "음성 녹음 기능 사용" 체크
3. "Whisper용 OpenAI API 키"에 OpenAI 키 등록 후 확인
4. Windows 설정 → 개인정보 및 보안 → 마이크에서 앱 권한 허용

### 앱 글꼴이 다르게 보여요

앱 글꼴은 함께 들어 있는 Pretendard(Regular·Medium·Bold 세 굵기)를 써요 (따로 설치할 필요 없음). 다르게 보이면 `assets/fonts/`의 글꼴 파일이 빠진 빌드라 Windows 기본 글꼴로 보이는 거예요.

### DB가 손상된 것 같아요

`~/.memo_slide/memos.db.bak`이 있으면 이름을 `memos.db`로 바꿔 되돌릴 수 있어요 (DB 구조를 바꾸거나 메모 색을 옮길 때 자동으로 만든 백업).

### `uv sync`가 OneDrive 폴더에서 실패해요

OneDrive의 하드 링크 제한 때문이에요. `uv cache clean` 뒤에 다시 해 보세요.
