## 설치하기

1. 아래 링크를 클릭하면 설치 파일이 바로 다운로드됩니다.
   **[⬇ SlideMemo-Setup.exe 다운로드](https://github.com/yujeong0411/SlideMemo/releases/latest/download/SlideMemo-Setup.exe)**
2. 다운로드된 파일을 실행합니다. PC 보호창이 뜨면 추가정보를 누르고 실행하세요.

![설치 화면](/tools/slide-memo/guide/install-setup.png)

<br />

3. 설치가 완료되면 바탕화면 아이콘과 시스템 트레이에서 실행됩니다.

![설치 완료](/tools/slide-memo/guide/install-complete.png)

<br />

<Callout type="info">
  제거할 때는 제어판 → 앱 → Slide Memo에서 제거하면 됩니다.
</Callout>

## 기본 사용법

화면 오른쪽(또는 왼쪽) 가장자리에 세로 탭 열이 표시됩니다.

![사이드바 설명](/tools/slide-memo/guide/sidebar.png)

1. 탭을 클릭하면 메모 본문이 펼쳐지고, 다시 클릭하거나 <Shortcut>Esc</Shortcut>를 누르면 접힙니다.
2. **새 메모** : 탭 열 하단 **＋** 버튼 또는 <Shortcut>Ctrl+N</Shortcut>
3. **휴지통** : 삭제된 메모 목록
4. **설정** : 메모장 기본 설정 및 AI 설정
5. **세로 이동** : 상단 손 모양 아이콘 드래그로 세로 위치 조절

<br />

![메모 우클릭 메뉴](/tools/slide-memo/guide/memo-context-menu.png)

- **고정 / 이전 버전 / 내보내기 / 휴지통으로 이동** : 해당 메모 탭을 **오른쪽 마우스**로 클릭

  <br />

![상단 고정·내보내기 버튼](/tools/slide-memo/guide/top-buttons.png)

- **고정 · 내보내기** : 본문 상단 정렬 드롭다운 옆 버튼으로도 실행 가능

  <br />

![사용자 지정 메모 색](/tools/slide-memo/guide/memo-color.png)

- **메모 색상 변경** : 제목 옆 색상 선택 (사용자 지정 색상도 가능)

  <br />

![정렬](/tools/slide-memo/guide/sort.png)

- **정렬**: 본문 상단 정렬 드롭다운

  <br />

![제목·본문 검색](/tools/slide-memo/guide/search.png)

- **검색**: <Shortcut>Ctrl+F</Shortcut> 또는 검색창에서 제목·본문 검색
- 필터링된 메모 탭만 노출

  <br />

![시스템 트레이](/tools/slide-memo/guide/system-tray.png)

- **가장자리 전환**: 시스템 트레이 아이콘 우클릭 → 왼쪽/오른쪽 전환
- **자동 저장**: 입력 후 0.6초 뒤 자동 저장

## 단축키 모음

### 메모 관리

| 단축키         | 기능                      |
| -------------- | ------------------------- |
| `Ctrl+N`       | 새 메모 생성              |
| `Ctrl+S`       | 즉시 저장                 |
| `Ctrl+F`       | 메모 검색                 |
| `Ctrl+E`       | 메모 파일로 내보내기      |
| `Ctrl+Alt+Z`   | 이전 버전 보기 · 되돌리기 |
| `Ctrl+Shift+C` | 메모 전체 텍스트 복사     |
| `Ctrl+Shift+D` | 현재 메모 휴지통으로 이동 |
| `Esc`          | 메모 접기 / AI 작업 취소  |

### 서식

| 단축키   | 기능      |
| -------- | --------- |
| `Ctrl+B` | 굵게      |
| `Ctrl+I` | 기울임    |
| `Ctrl+U` | 밑줄      |
| `Ctrl+K` | 링크 삽입 |

### 날짜·시간 삽입

| 단축키         | 형식        | 예시                    |
| -------------- | ----------- | ----------------------- |
| `F5`           | 메모장 포맷 | 오전 09:30 2025-05-26   |
| `Ctrl+;`       | 날짜만      | 2025-05-26              |
| `Ctrl+Shift+;` | 시간만      | 09:30                   |
| `Ctrl+Alt+;`   | ISO 형식    | 2025-05-26T09:30:00     |
| `Ctrl+Shift+H` | 한국식      | 2025년 05월 26일 월요일 |

### AI 기능

| 단축키       | 기능           |
| ------------ | -------------- |
| `Ctrl+Alt+S` | 요약           |
| `Ctrl+Alt+T` | 번역 (한↔영)   |
| `Ctrl+Alt+P` | 맞춤법 교정    |
| `Ctrl+Alt+H` | 제목 자동 생성 |
| `Ctrl+Alt+K` | 키워드 추출    |

## AI 기능 사용하기

설정(⚙)에서 API 키를 입력하고 AI 기능을 활성화합니다.

![AI 기능 설정 창](/tools/slide-memo/guide/ai-setting.png)

<br />
활성화하면 에디터 하단에 기능 버튼이 표시됩니다.

![AI 기능 버튼](/tools/slide-memo/guide/ai-toolbar.png)

| 기능         | 설명                                  |
| ------------ | ------------------------------------- |
| 요약         | 메모 내용을 간결하게 요약합니다.      |
| 번역 (한↔영) | 한국어↔영어 자동 감지 후 번역합니다.  |
| 맞춤법 교정  | 철자·문법 오류를 수정합니다.          |
| 제목 생성    | 내용 기반으로 제목을 자동 생성합니다. |
| 키워드 추출  | 핵심 키워드 5~10개를 추출합니다.      |

단축키, 서식바 버튼, 에디터 우클릭 메뉴에서 모두 실행할 수 있습니다.
진행 중 취소하려면 <Shortcut>Esc</Shortcut>를 누르세요.

## 이전 버전으로 되돌리기

메모는 자동 저장되기 때문에, 내용을 실수로 지우면 그대로 확정됩니다.
이를 대비해 덮어쓰기 직전의 내용을 자동으로 남겨 둡니다.

여는 방법은 두 가지입니다.

- 메모 탭 **오른쪽 마우스** → **이전 버전…**
- <Shortcut>Ctrl+Alt+Z</Shortcut>

![이전 버전 창](/tools/slide-memo/guide/version-history.png)

<br />

목록에서 시점을 고르면 내용을 미리 볼 수 있고, **이 버전으로 되돌리기**를 누르면 적용됩니다.

| 항목      | 내용                                                |
| --------- | --------------------------------------------------- |
| 저장 주기 | 5분 간격 (그 사이 변경은 하나로 묶임)               |
| 보관 개수 | 메모당 최근 20개                                    |
| 보관 범위 | 어느 시점에 지워도 **최대 5분 전** 상태로 복구 가능 |

<Callout type="info">
  되돌리기 직전 상태도 함께 저장되므로, 잘못 되돌렸다면 다시 이전 버전에서
  원래대로 돌아올 수 있습니다.
</Callout>

**실행 취소(<Shortcut>Ctrl+Z</Shortcut>)** 는 다른 메모를 보고 돌아와도 그대로 유지됩니다.
다만 앱을 종료하면 사라지므로, 그 이후는 이전 버전 기능으로 복구하세요.

## 파일로 내보내기

메모를 파일로 저장할 수 있습니다.

- 본문 상단 정렬 옆 **내보내기** 버튼
- 메모 탭 **오른쪽 마우스** → **내보내기…**
- <Shortcut>Ctrl+E</Shortcut>

![내보내기 저장 창](/tools/slide-memo/guide/export-dialog.png)

<br />

| 형식   | 용도                   | 유지되는 것                   |
| ------ | ---------------------- | ----------------------------- |
| `.odt` | Word에서 열기          | 표·목록·굵게·색상·이미지      |
| `.md`  | 마크다운 편집기·깃허브 | 제목·표·목록·서식 (색상 제외) |
| `.txt` | 순수 텍스트            | 글자만                        |

저장 대화상자에서 파일 형식을 고르면 그 형식으로 저장됩니다. 제목은 문서 맨 위에 들어갑니다.

<Callout type="info">
  Google 드라이브에 보관하려면 Drive 데스크톱 앱을 설치한 뒤, 내보내기 위치를
  드라이브 폴더로 지정하면 됩니다.
</Callout>

## 휴지통

삭제한 메모는 30일간 휴지통에 보관됩니다. 탭 열 하단 🗑 버튼으로 열 수 있습니다.

![휴지통](/tools/slide-memo/guide/trash.png)

- 휴지통에서도 **검색과 정렬**을 그대로 사용할 수 있습니다
- 메모를 클릭하면 내용을 미리 볼 수 있습니다
- 복원 · 영구 삭제는 해당 탭을 **오른쪽 마우스**로 클릭
  <br />

![휴지통 모드 탭 열 버튼](/tools/slide-memo/guide/trash-column.png)

- 탭 열 하단의 **전체 비우기**, **닫기** 버튼으로 휴지통을 비우거나 빠져나옵니다

## 기타 설정

설정(⚙) → **일반** 탭에서 아래 항목 조정 가능.

![일반 설정](/tools/slide-memo/guide/settings.png)

1. **앱 위치** : 오른쪽 / 왼쪽 가장자리 선택 (트레이 우클릭으로도 전환 가능)  
   **앱 표시 방식** : 트레이만(작업표시줄에 안 뜸) · 작업표시줄만 · 둘 다 표시
2. **인덱스 탭 설정** : 가로 폭(24-60px) · 세로 길이(60-200px) 슬라이더
3. **시스템 시작 시 자동 실행** : Windows 로그인 시 자동 시작
4. **메모 앱 펼칠 때 클립보드 자동 감지** : 메모를 펼칠 때 클립보드에 이미지가 있으면 새 메모 생성 배너 표시

![클립보드 감지 배너](/tools/slide-memo/guide/clipboard-settings.png)

## 문제 해결

1. **앱이 화면에 보이지 않아요**

시스템 트레이(우측 하단 시계 근처) 아이콘을 클릭하거나 더블클릭하세요.

2. **탭 열이 너무 좁거나 넓어요**

설정 → 인덱스 탭 폭 슬라이더에서 조절하세요.

3. **AI 기능 버튼이 보이지 않아요**

설정 → AI 탭에서 API 키를 입력하고 AI 기능을 활성화하세요.

4. **실수로 지운 내용을 되돌리고 싶어요**

메모 탭을 오른쪽 마우스로 클릭 → **이전 버전…** 또는 <Shortcut>Ctrl+Alt+Z</Shortcut>.
메모 자체를 지웠다면 휴지통에 30일간 남아 있습니다.

5. **데이터 위치**

메모 데이터는 `%USERPROFILE%\.memo_slide` 폴더에 SQLite 파일(`memos.db`)로 저장됩니다.
첨부한 이미지는 같은 폴더의 `images` 안에 들어갑니다.
