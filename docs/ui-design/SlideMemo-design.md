# SlideMemo 디자인 규칙 v2

CC가 QSS 테마 파일을 만들 때 이 문서를 기준으로 삼는다.
값은 이 문서에서만 정하고, 코드에는 토큰 이름으로만 쓴다.
1.0판에서 정했던 남보라, 먹색 후보, 그리고 다른 참고 파일(라프텔·NOL·뱅크샐러드·One UI)에서 가져온 규칙은 모두 버렸다.

## 0. 두 파일의 역할

| 맡는 것 | 출처 | 이유 |
|---|---|---|
| 밝은 화면 색(회색 계단, 인디고 포인트, 빨강), 글자 크기, 간격(4px 배수), 문구 말투, 단추 위계, 선택 칩 | **교보문고** | 앱 화면은 흰색·옅은 회색으로 비우고 색은 콘텐츠(책 표지)가 채운다. SlideMemo도 색은 메모가 채운다 |
| 어두운 화면 색, 데스크탑 부품 규격(높이·반경·메뉴·툴팁·대화창·체크박스·탭), 마우스 올림·누름·비활성·포커스 표현, 그림자 | **Vapor UI** | 교보문고는 어두운 화면 값이 없고 모바일·쇼핑 부품 위주다. Vapor는 개발 도구용이라 데스크탑 부품이 다 있다 |
| 글꼴 | **Vapor UI** (Pretendard) | 앱에 이미 들어 있다 |

규칙 하나로 정리하면: **값(색)은 교보, 방식(크기·상태)은 Vapor.**
두 파일 모두 이 원칙에 동의한다.
- 장식 없음: 그라데이션·유리 효과·무늬·이모지를 쓰지 않는다.
- 층은 1px 선과 옅은 면 차이로 나눈다.
- 그림자는 떠 있는 것에만 준다.

메모 색 8가지는 Vapor 팔레트 값을 그대로 쓴다. 두 파일 어디에도 없는 것은 직접 만든 색의 계산(3.0.1)과 메모 면 위의 색 계산(3.1~3.2)뿐이고, 이 둘은 SlideMemo 고유 규칙으로 따로 표시했다.

어두운 화면의 포인트는 교보 인디고 계단에서 밝은 단(blue-300·400)을 골랐다. 교보 원래 값 `#5055B1`은 어두운 바탕(`#282828`) 위에서 2.3:1로 묻히기 때문이다.

빨강은 교보의 "부정" 빨강 `#EC1F2D` 대신 같은 계열의 더 진한 단 `#B01219`를 쓴다. 원래 값은 흰 글자 대비가 4.37:1이라 단추 글자 기준(4.5:1)에 못 미친다. 교보가 "부정 빨강은 절제해서 쓴다"고 한 원칙은 그대로 지킨다. 위험 단추는 휴지통 비우기와 영구 삭제, 두 곳에만 쓴다.

`fg_hint`(밝은 화면)는 흰 면(`bg_canvas`·`bg_raised`) 위에서만 쓴다. `bg_sunken` 위에서는 4.16:1이라 기준에 못 미치므로, 그 자리에는 `fg_secondary`를 쓴다.

**Windows 강조색은 따르지 않는다.** 지금 OK 단추와 체크박스가 분홍으로 나오는 것이 이것 때문이다. `QPalette`의 Highlight·Accent·Link를 위 토큰으로 고정한다.

### 1.2 선택 표시는 네 가지만 쓴다

| 상황 | 표시 | 출처 |
|---|---|---|
| 목록에서 하나 고르기 (정렬, 콤보 목록, 메뉴 라디오) | 왼쪽 체크 아이콘(`fg`). 굵기와 바탕은 바꾸지 않는다 | Vapor select |
| 칩·분할 단추 (정렬 방향, 필터) | `chip_selected` 면 + 반대 색 글자 | 교보 chip |

어느 경우든 색만으로 표시하지 않는다. 체크, 막대, 채운 면처럼 모양이 함께 바뀐다(교보·Vapor 공통).

## 2. 글자, 간격, 크기, 반경, 그림자, 움직임

### 2.1 글꼴
- Pretendard 하나만 쓴다(Vapor).
- 굵기는 400 / 500 / 700 세 가지다(교보·Vapor 공통, 600은 없다).
  - 지금 앱에는 Regular·Bold만 있다. **Pretendard-Medium을 assets/fonts에 추가**한다.
- 자간은 -0.01em이다(교보). Qt에서는 `QFont.setLetterSpacing(PercentageSpacing, 99)`로 근사한다.
- 날짜·시각·개수·px 값에는 고정폭 숫자를 켠다: `QFont.setFeature("tnum", 1)`.
- 라이선스: Pretendard OFL 전문을 `assets/fonts/OFL.txt`로 넣고 배포본·설치본에 포함한다.
- 메모 제목·세로 탭은 항상 Pretendard를 쓴다.
- 글자 다듬기는 회색조로 한다(ClearType 색 번짐 없음). 앱 글꼴과 메모 본문 글꼴에 `QFont.StyleStrategy.NoSubpixelAntialias`를 주고, Qt의 Windows 글꼴 엔진은 FreeType(`QT_QPA_PLATFORM=windows:fontengine=freetype`)을 쓴다. 기본 엔진인 DirectWrite는 이 옵션을 무시해 번짐이 그대로 남는다.
- 힌팅은 `PreferVerticalHinting`이다. FreeType에서 `PreferNoHinting`과 비교하면 150%에서는 픽셀이 같고, 100%에서는 세로 힌팅의 가로획이 조금 더 또렷하다.
- 메모 본문은 사용자가 고른 글꼴을 쓰고, 고른 적이 없으면 Pretendard 16px을 쓴다. 지금의 D2Coding → Consolas 순서는 없앤다.

### 2.2 글자 크기 (교보 스케일, Vapor와 값이 같음)

| 토큰 | 크기/줄높이 | 굵기 | 출처 | 쓰임 |
|---|---|---|---|---|
| `caption` | 12 / 18 | 400 | 교보 text-m = Vapor body3 | 배지 숫자, 슬라이더 값, 단축키, 툴팁 |
| `label` | 12 / 18 | 500 | Vapor subtitle2 | 묶음 제목, 세로 탭 제목 |
| `body` | 14 / 22 | 400 | 교보 text-l = Vapor body2 | UI 기본: 메뉴, 입력, 설정 항목, 대화창 설명 |
| `body_strong` | 14 / 22 | 500 | Vapor subtitle1 | 단추, 탭, 팝업 제목 |
| `memo_body` | 16 / 24 | 400 | 교보 text-xl | 메모 본문 기본값 |
| `title` | 18 / 28 | 700 | 교보 title-xs | 메모 제목, 대화창 제목 |

- 12px보다 작은 글자는 쓰지 않는다(교보 최소값). 지금 흩어져 있는 7~11pt 값은 모두 위 표로 올린다.
- 대화창 제목 18/700은 Vapor dialog 규격과도 같다.

### 2.3 간격
- 4px 배수만 쓴다. 예외는 2px 하나다(교보): `2 · 4 · 8 · 12 · 16 · 20 · 24 · 32`.
- 메인 창 안쪽 12, 묶음 사이 8.
- 대화창은 Vapor 규격을 따른다: 머리 높이 56·좌우 24, 본문 좌우 24, 아래 단추 줄 위아래 16·좌우 24.

### 2.4 컨트롤 높이 (Vapor 사다리)

| 크기 | 높이 | 좌우 여백 | 글자 | 쓰임 |
|---|---|---|---|---|
| `sm` | 24 | 8 | 14/500 | 서식바 아이콘 단추, AI 칩, 말풍선·팝업 안 단추, 녹음 줄 단추 |
| `md` | 32 | 12 | 14/500 | 검색 칸, 정렬 콤보, 대화창·설정 단추, 입력 칸, 콤보, 메뉴 항목, 달력 칸 |

- 단추 사이·탭 사이 간격은 8 이상으로 둔다.
- 아이콘은 컨트롤 크기의 절반, 최소 16이다(Vapor).

### 2.5 반경
- **부품은 모두 8**이다(Vapor 기본값, 교보 4배수와도 맞음). 단추(크기 무관), 입력, 콤보, 메뉴·메뉴 항목, 팝업, 툴팁, 토스트, 대화창, 말풍선, 달력 칸이 여기에 해당한다.
- 체크박스와 색 견본은 4다(Vapor checkbox md).
- 큰 면은 12다(교보 카드 12~24 구간의 가장 작은 값). 메모 창 바깥, 바 단추 묶음이 해당한다.
- 세로 탭은 안쪽 모서리만 6이다(9장 22).
- 원형(`9999px`): 칩, 배지, 색 점, 슬라이더 손잡이, 녹음 단추.

### 2.6 그림자 (Vapor 4단 중 셋)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `shadow_sm` | `0 1px 3px rgba(0,0,0,.20)` | 슬라이더 손잡이 |
| `shadow_md` | `0 4px 10px rgba(0,0,0,.20)` | 메뉴, 팝업, 토스트, 말풍선, AI 진행 표시 (툴팁은 그림자 없음) |
| `shadow_xl` | `0 16px 32px rgba(0,0,0,.20)` | 대화창 |

- 떠 있는 면은 `1px line` 테두리와 그림자를 함께 쓴다.
- 메인 창, 카드, 단추, 입력 칸에는 그림자를 주지 않는다.
- Qt 구현: 자체 팝업에는 `QGraphicsDropShadowEffect(blurRadius=10, offset=(0,4), color=rgba(0,0,0,.20))`를 준다. QMenu·툴팁은 Windows가 그려 주는 그림자를 쓰고, 둥근 모서리와 함께 안 되면 1px `line`만 남긴다.

### 2.7 상태 표현 (Vapor)

| 상태 | 표현 |
|---|---|
| 마우스 올림 | 면 색을 바꾸지 않고 `overlay_hover`(8%)를 겹친다. 크기·위치 변화 없음 |
| 누름 | `overlay_press`(16%). 주요 단추는 `accent_press` |
| 비활성 | 글자·아이콘 `fg_disabled`, 올림 효과 끔. (Vapor는 투명도 0.32지만 QSS에 투명도가 없어 색으로 대신함) |
| 키보드 포커스 — 단추·탭·체크박스 | 2px `focus` 테두리, 2px 띄움. **절대 끄지 않는다** |
| 키보드 포커스 — 입력 칸·콤보 | 테두리(1px)를 `accent`로 바꾼다. 마우스만 올렸을 때는 `line_control` 그대로 |

### 2.8 움직임 (교보)
- 빠름 150ms(올림·포커스·팝업 나타남), 기본 240ms(메모 창 펼침·접힘)를 쓴다.
- 곡선은 `cubic-bezier(0.4, 0, 0.2, 1)`이다(교보·Vapor 공통).
- 튀는 움직임, 크기 변화는 쓰지 않는다.
- 토스트는 4초 머문다(교보).
- 로딩 표시는 1초 넘게 걸릴 때만 보이고, 한 화면에 하나만 콘텐츠 가운데에 둔다(교보).

## 3. 메모 색

### 3.0 종이 톤 8가지 (Vapor 팔레트)
메모 면은 흰 종이에 색 기운만 남긴 Vapor `050` 단이다. 메모끼리는 탭 바깥쪽(모니터 쪽) 4px 색 띠로 구분하고, 띠는 Vapor `500` 단이다.
어두운 화면에서는 메모 면이 모두 `#282828`(Vapor canvas)이 되고, 띠만 Vapor 어두운 `500` 단으로 남는다.
**그라데이션은 없다.** 기본 색에서도, 직접 만드는 색에서도 없앤다.

| 이름 | 밝은 화면 면 (050) | 밝은 화면 띠 (500) | 어두운 화면 면 | 어두운 화면 띠 (dark-500) |
|---|---|---|---|---|
| 회색 | `#F4F4F4` | `#767676` | `#282828` | `#898989` |
| 노랑 | `#FFF7E7` | `#A96800` | `#282828` | `#BE7B00` |
| 주황 | `#FFF6F1` | `#D34701` | `#282828` | `#E65F08` |

- 띠와 메모 면의 대비는 모두 4.1:1 이상이다. 비텍스트 기준 3:1을 넘는다.
- 면 위 글자는 12:1 이상이다.
- 새 메모의 기본 색은 노랑이다.

### 3.0.1 직접 만들기 (한 색) — SlideMemo 고유 규칙
사용자는 색을 **하나만** 고른다. 고른 색이 띠가 되고, 나머지는 앱이 계산한다.
1. 고른 색을 OKLCH로 바꾼다 → (L, C, H).
2. 밝은 화면 면은 `oklch(0.975, min(C × 0.15, 0.022), H)`다. Vapor `050` 단과 같은 밝기다.
3. 밝은 화면 띠는 고른 색 그대로 쓴다. 다만 면과의 대비가 3:1 미만이면 L을 0.02씩 낮춰 3:1을 넘긴다.
4. 어두운 화면 면은 `#282828`이다. 띠는 고른 색에서 시작해, `#282828`과의 대비가 3:1 미만이면 L을 0.02씩 올린다.
5. 예: `#E07A5F` → 면 `#FFF2EE`, 밝은 띠 `#D26E53`(3.15:1), 어두운 띠 `#E07A5F`(5.0:1).
- 직접 만든 색은 "직접 만든 색" 줄에 최근 것부터 6개까지 남긴다.
- 지금 있는 "색 점 우클릭 메뉴"(이름 바꾸기·지우기)는 이 줄에서 그대로 쓴다.

### 3.0.2 이미 있는 메모 옮기기 (업데이트 후 처음 켤 때 한 번)
- 지금 프리셋과 그라데이션 메모는 색상(H)이 가장 가까운 새 프리셋으로 바꾼다. 그라데이션은 첫 번째 색을 기준으로 한다. 채도가 낮으면(C < 0.01) 회색으로 바꾼다.
  - 예: sunrise·민트 → 초록, blossom → 분홍, 노랑 탭 → 노랑, 하늘색·남색 → 파랑.
- 사용자가 직접 만든 단색은 3.0.1 규칙으로 바꾼다. 원래 색이 띠가 된다.
- 바꾼 뒤 지금 있는 "팔레트가 바뀌었어요" 안내 창(`_show_palette_notice`)을 한 번 띄운다.
  - 문구: "메모 색이 차분한 종이 톤으로 바뀌었어요. 색은 제목 옆 색 단추에서 언제든 바꿀 수 있어요."
- 옮기기 전 색 값은 DB에 남겨 둔다(되돌리기 대비).

### 3.1~3.2 메모 면 위의 색 — SlideMemo 고유 규칙
두 파일 모두 "색은 콘텐츠가 채운다"고만 하고, 콘텐츠 색 위에 컨트롤을 얹는 규칙은 없다. 그래서 이 부분만 SlideMemo가 직접 정한다. 종이 톤에서는 면이 거의 흰색이라 대부분 검정 먹색이 되지만, 어두운 화면과 직접 만든 색을 위해 계산은 그대로 둔다.

### 3.1 먹색 고르기
메모 면과 `#1B1D22`·`#FFFFFF`의 대비를 각각 구해, 더 큰 쪽을 `ink`로 정한다. 밝은 화면은 `#1B1D22`, 어두운 화면은 `#FFFFFF`가 된다.

### 3.2 계산 토큰 (`ink`를 메모 색 위에 섞은 비율)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `memo_fg` | `ink` 100% | 제목, 본문 |
| `memo_fg_secondary` | `ink` 76% | 보조 글자, 서식바·바 아이콘 |
| `memo_field` | 먹색이 검정이면 흰색 55%, 흰색이면 검정 22% | 검색 칸·정렬 콤보·AI 칩 안쪽 면 |
| `memo_hint` | 필드 위 `ink` 68% | 검색 칸 자리표시자 |
| `memo_border` | `ink` 55% | 검색 칸·콤보·칩 테두리 (3:1 이상) |
| `memo_divider` | `ink` 14% | 서식바 위 선, 서식 묶음 구분선 |
| `memo_edge` | `ink` 24% | 메모 창 바깥 테두리, 탭 사이 선 |
| `memo_frame` | `ink` 18% | 본문 칸 테두리 (영역 구분용, 3:1 대상 아님) |
| `memo_hover` / `memo_selected` | `ink` 8% / 16% | Vapor 올림·누름 비율을 메모 면에 그대로 적용. 켜진 서식 단추는 16% |
| `memo_scroll` | `ink` 30% | 본문 스크롤 손잡이 |
| `memo_link` | 먹색이 검정이면 `#5055B1`, 흰색이면 `#AEB1DF`. 4.5:1 미만이면 `ink` + 밑줄 | 새로 만드는 링크 |

- 종이 톤 8가지와 어두운 면으로 계산한 대비는 본문 14 이상, 보조 7 이상이다. 직접 만든 색도 면 밝기가 고정(L 0.975)이라 같은 수준이다.
- 그래도 기준(글자 4.5, 테두리 3.0)에 못 미치면 비율을 5%씩 올려 다시 계산한다. 이 검사는 계산 함수 안에 넣는다.
- **포인트 색(`accent`)은 메모 면 위에 직접 칠하지 않는다.** 포인트 색이 필요한 요소(녹음 줄, AI 진행 표시)는 `bg_raised` 카드에 담아 띄운다.
- 본문 우클릭 메뉴, 팝업, 툴팁은 메모 색을 물려받지 않는다. 항상 1장 토큰을 쓴다.
- 텍스트 선택 색은 `accent` 면 + 흰 글자로 고정한다(6.41:1).
- 이미 저장된 메모의 인라인 링크 색은 그대로 둔다. 새 링크에는 인라인 색을 넣지 않고 `QTextDocument.setDefaultStyleSheet`로 칠한다.

## 4. 부품별 규칙

### 4.1 바와 세로 탭 — 모니터 끝에 붙는다
SlideMemo는 모니터 왼쪽 또는 오른쪽 끝에 붙는 메모장이다. 바와 메모 창은 하나의 덩어리로 가장자리에 붙는다.

- **바는 모니터 끝에 딱 붙는다.** 바깥(모니터 쪽)에는 여백도, 테두리도, 둥근 모서리도 없다.
  - 마우스를 화면 끝까지 밀어도 탭이 눌려야 한다(가장자리 클릭 영역).
  - 둥근 모서리는 화면 안쪽에만 준다: 바 단추 묶음 12, 탭 8.
- 순서는 위에서부터 손잡이(40×40) → 세로 탭 → 아래 묶음(새 메모·휴지통·모두 접기, 32×32 단추)이고, 사이는 4다.
  - 손잡이와 아래 묶음: `bg_canvas` + 1px `line`(모니터 쪽 변 제외).
- **세로 탭은 틈 없이 서로 붙어 있다.** 안쪽(화면 가운데 쪽) 두 모서리만 반경 6으로 둥글고, 바깥쪽(화면 가장자리 쪽) 두 모서리는 직각이다. 붙은 탭 사이의 안쪽 모서리에는 작은 홈이 생긴다. 선은 안쪽 변과 아래쪽만 긋는다(위쪽 선은 윗 탭의 아래쪽 선이 맡아 1px을 유지한다).
- 탭 사이는 1px `memo_edge` 선으로만 나눈다. 탭 크기는 40×112(설정의 탭 너비·높이 기본값)이다.
- 탭 면은 그 메모의 면 색이고, **바깥쪽(모니터 쪽) 4px는 그 메모의 띠 색**이다. 모니터 끝에 책등처럼 색 띠가 줄지어 보인다.
- 제목은 `label` 12/18/500 `memo_fg`, 열린 탭만 700이다. 시계방향 90도로 눕혀 위에서 아래로 읽는다(양쪽 가장자리 모두 같다).
  - 줄 수는 (탭 폭 − 띠 4 − 안쪽 여백 8) ÷ 18이다. 폭 40이면 한 줄, 48이면 두 줄이다. 줄은 띄어쓰기에서 나누고, 마지막 줄 끝에서만 "…"로 줄인다.
  - 고정한 탭은 핀 아이콘 대신 책갈피 리본을 QPainter로 그린다. 읽기 시작 쪽 끝에 띠와 4px 띄워 매달리고, 폭 10·길이 14, 끝은 가운데가 4px 파인 V 모양이다. 색은 그 메모의 띠 색(`memo_band`)이고 테두리와 그림자는 없다. 글자는 고정하지 않은 탭과 같은 자리에서 시작한다.
  - 고정한 탭의 툴팁은 제목 뒤에 " · 고정됨"을 붙이고, 제목이 다 보여도 띄운다.
- **열린 메모의 탭은 메모 창과 이어진다.**
  - 탭과 창 사이 경계선을 없애고, 탭 안쪽 둥근 모서리도 없앤다. 탭이 창 쪽으로 1px 넓어진다.
  - 제목은 700으로 올린다.
  - 나머지 탭과 창 사이에는 `memo_edge` 1px 선이 남는다.
  - 색을 따로 칠하지 않아도 "어느 메모가 열렸는지"가 모양으로 보인다.
- 메모 창: 모니터 쪽 모서리 0, 안쪽 모서리 12, 1px `memo_edge`(바 쪽 변 제외). 창 위끝은 손잡이 위끝과 맞춘다.
- 휴지통 개수 배지: Vapor badge sm 원형(높이 20, 2px `bg_canvas` 테두리 포함, 좌우 4), `bg_muted` + `fg_secondary`, `caption` 12/500, 고정폭 숫자. 100 이상은 "99+"다.
  - 배지는 아이콘 오른쪽 위 꼭짓점 쪽에 두고, 아이콘의 아래 2/3는 가리지 않는다.
  - 빨강을 쓰지 않는다. 경고가 아니라 개수 정보이기 때문이다.
- 휴지통 툴팁은 "휴지통 (메모 N개)", 비어 있으면 "휴지통 (비어 있음)"이다. 비어 있어도 아이콘은 남고, 배지만 사라진다.
- 왼쪽에 붙을 때는 모든 것을 좌우로 뒤집는다. "모두 접기" 화살표 방향도 바꾼다.
- **동기화 경고 단추** (2.1.0, 동기화를 연결한 경우만):
  - 평소에는 없다. 바에 아무것도 늘리지 않는다.
  - 문제가 있을 때만 아래 묶음의 휴지통 단추 바로 아래에 나타난다. 같은 32 높이 바 단추이고, 아이콘은 `triangle-alert` 18을 `danger` 색으로 칠한다.
  - 나타나는 경우: 다시 연결이 필요함, Drive 저장 공간이 가득 참, 1시간 넘게 연결할 수 없음(잠깐 끊긴 것은 띄우지 않는다).
  - 툴팁은 그 상태의 문구다. 예: "Google Drive 저장 공간이 가득 차서 동기화를 멈췄어요".
  - 누르면 설정 창을 동기화 탭으로 연다.
- 탭에 마우스를 올리면 `memo_hover`, 툴팁으로 메모 제목 전체를 보여 준다(긴 제목이 잘리기 때문).

- 잠깐 숨기기("»")를 누르면 화면 가장자리에 32×32 로고 단추가 남는다.
  - 바가 있던 높이, 붙어 있던 쪽 가장자리에 붙는다. 위아래로 끌면 옮겨지고 저장되며, 끄는 동안은 누름으로 처리하지 않는다.
  - 바깥쪽은 직각, 안쪽 두 모서리는 반경 8이다. 면 `bg_canvas`, 테두리 1px `line`, `shadow_sm`. 가운데에 새 로고(slidememo-20)를 20px로 로고 색 그대로 넣는다.
  - 마우스를 올리면 면에만 `overlay_hover`를 겹친다. 툴팁은 "메모장 펼치기 (Ctrl+Shift+Z)"다. 누르면 바가 돌아온다.
  - 다른 앱이 그 모니터를 전체 화면으로 쓰면 숨긴다. 트레이와 Ctrl+Shift+Z는 그대로다. Tab 포커스는 받지 않는다.

### 4.2 메인 창 (메모 면)
- 위 줄: 검색 칸(`md` 32, `memo_field`, `memo_border` 안쪽 1px 테두리, 돋보기 16), 정렬 콤보("수정일순" + 셰브런), 고정·내보내기 아이콘 단추(32).
  - 컬러 이모지 돋보기는 단색 선 아이콘으로 바꾼다.
- 제목 줄: `title` 18/28/700. 오른쪽에 **색 단추 하나**를 둔다(`sm` 24: 지름 14 띠 색 원 + 셰브런). 누르면 "메모 색" 팝업(4.4)이 열린다.
  - 지금처럼 색 점을 여러 개 늘어놓지 않는다. 제목 줄이 가벼워지고, 좁은 폭에서도 줄이 넘치지 않는다.
- 서식바: `sm` 24 아이콘 단추, 사이 2, 묶음 사이 `memo_divider` 세로선. 켜진 서식은 `memo_selected`.
  - 좁은 폭에서 줄을 바꿀 때는 묶음째 넘긴다.
- 본문 칸: 메모 면 그대로 두고 1px `memo_frame`, 반경 8, 안쪽 12. 포커스가 들어오면 테두리를 `memo_border`로 바꾼다.
- 표: 칸 선 `ink` 30%, 머리 칸 `ink` 6% + 500.
- 스크롤바: 폭 6, 원형 손잡이 `memo_scroll`, 홈 없음.
- 녹음 중:
  - 마이크 단추를 `danger_fill` 원 + 흰 아이콘으로 바꾼다.
  - 서식바 아래에 `bg_raised` 카드를 띄운다: `danger` 점 + "녹음 중 00:12" + "중지하기"(보조 `sm`).
- AI 단추 줄: `sm` 24 칩(`memo_field` + `memo_border`, 14/500), 동사로 쓴다: 요약하기 / 번역하기 / 맞춤법 고치기 / 제목 짓기.
- AI 진행:
  - 1초가 넘으면 본문 가운데에 `bg_raised` 카드 하나를 띄운다: 원형 스피너(`accent`) + "요약하는 중이에요" + "취소"(ghost `sm`).
  - 끝나는 시점을 모르므로 막대 대신 원을 쓴다.
- 토스트(Vapor 규격):
  - 면은 `contrast` + 흰 글자 14/22, 반경 8, 안쪽 12·16, `shadow_md`.
  - 창 위쪽 가운데에서 내려오고, 4초 머문다.
  - 동작 단추는 하나만 둔다("되돌리기", 흰 글자 밑줄 500).
  - 본문을 가리지 않도록 아래가 아니라 위에 띄운다.
- 검색어 강조: `highlight` 면 + `#1B1D22` 글자(메모 색과 무관하게 고정).
- 빈 메모 자리표시자: `memo_hint`.

### 4.3 메뉴 (Vapor menu)
- 면 `bg_raised`, 1px `line`, 반경 8, 안쪽 4, `shadow_md`, 최소 폭 200.
- 항목:
  - 높이 32, 반경 8, 오른쪽 여백 12, 왼쪽 8 + 아이콘 16 + 사이 8.
  - 글자 `body` 14/400 `fg`. 아이콘은 `fg_secondary`, 단축키는 `fg_hint` 12 고정폭.
  - 하위 메뉴 화살표는 `fg_secondary`.
- 묶음 제목은 12/500 `fg_secondary`, 구분선은 1px `line` + 위아래 4.
- 올림 8%, 누름 16%.
- 위험 항목(휴지통으로 옮기기, 영구 삭제)은 `danger` 글자·아이콘으로 맨 아래 묶음에 둔다.
- 메뉴 이름은 동작 동사로 쓴다: 이전 버전 보기, 휴지통으로 옮기기, 반대쪽 가장자리로 옮기기.
- **본문 우클릭 메뉴가 투명해지는 문제:**
  - 원인인 `QTextEdit#editor QWidget` 규칙의 범위를 `QTextEdit#editor > QWidget#qt_scrollarea_viewport`로 좁힌다.

### 4.4 자체 팝업 (정렬 · 글꼴 · 색 · 날짜)

## 6. 구현 (CC용)

### 6.1 파일 구조
```
src/theme/
  tokens.py       # LIGHT, DARK 딕셔너리 + 글자·간격·크기 상수 (1~2장)
  memo_tokens.py  # memo_tokens(stops) -> dict (3장, 대비 검사·링크 대체 포함)
  app.qss         # 앱 껍데기. $토큰 자리표시자 (string.Template)
  memo.qss        # 메모 창 안쪽. $memo_토큰 자리표시자
  apply.py        # apply_theme(app, mode), apply_memo(window, stops), 아이콘 다시 칠하기
```
- `setStyleSheet`는 두 곳만 남긴다: 앱 전체(`app.qss`), 메모 창(`memo.qss`, 메모 색이 바뀔 때).
  - 지금의 46곳 호출과 129회 hex를 모두 토큰으로 옮긴다.
  - 옮긴 뒤 `src/`에서 `#[0-9a-fA-F]{6}`를 찾으면 `tokens.py` 말고는 나오지 않아야 한다.
- 부품 구분은 `objectName`과 `setProperty("variant", ...)`로 한다. 속성을 바꾼 뒤에는 `style().unpolish/polish`를 부른다.
- 입력 칸 테두리(Vapor는 inset 그림자)는 QSS에서 `border: 1px solid`로 그린다. 포커스 때 두께는 그대로 두고 색만 바꿔 자리가 밀리지 않게 한다.

### 6.2 화면 모드
- 시스템 감지는 `QGuiApplication.styleHints().colorScheme()` + `colorSchemeChanged` 신호로 한다.
- `app.setStyle("Fusion")`으로 QSS가 어디서나 같게 그려지게 하고, `QPalette`도 토큰으로 채운다.
- 바꾸는 순서: 팔레트 → app.qss → 열린 메모 창 memo.qss → 아이콘 다시 칠하기.

## 8. 로고

- 모양: 종이 한 장 + 오른쪽 옆에 붙은 세로 탭 셋. 맨 위 탭은 종이와 이어져 있다(앱의 "열린 탭"과 같은 모양).
- 색:
  - 종이와 맨 위 탭은 `#6F73C0`(교보 blue-500, 부드러운 인디고)이다. 앱 포인트 `accent`(`#5055B1`)보다 한 단 밝은 이웃 색이다.
  - 나머지 탭은 `#FFD8E2`(Vapor pink-100), `#FFDD95`(Vapor yellow-100)이다.
  - 글줄은 흰색 90%다.
  - 밝은 작업 표시줄 3.70:1, 어두운 작업 표시줄 3.79:1로 어느 바탕에서나 비슷하게 보인다.
- 크기별 판: 16·20·24·32·48·64·128·256px를 따로 그렸다.
  - 48px 이상은 글줄 3개, 그보다 작으면 2개다.
  - 선 굵기는 작을수록 굵게 했다(64 단위 그리드 기준 4.5 → 2.5).

  - `SlideMemo.ico`: 8가지 크기 모두 들어 있다. 크기마다 그 크기용 그림이 들어 있어 줄여서 흐려지지 않는다.
  - `slidememo.svg`: 기본, 256 기준이다.
  - `slidememo-{크기}.svg/png`
- 쓰는 곳:
  - 앱 창·작업 표시줄: `SlideMemo.ico` (PyInstaller spec의 `icon=`, `QApplication.setWindowIcon`).
  - 트레이: 같은 로고를 쓴다. `QIcon`에 16·20·24·32 PNG를 모두 `addFile`로 넣어 배율에 맞는 판이 고르게 한다. 지금의 "트레이 대체 아이콘" 직접 그리기는 없앤다.

## 9. 구현 중 결정 (2026-11-10)

구현을 시작하며 정한 것을 번호대로 적는다. 앞으로는 이 문서와 이 기록이 기준이다. 앞 장과 어긋나면 이 장을 따른다.
이번 개편에서는 기능을 새로 만들지도, 없애지도 않는다.

1. **Pretendard-Medium:** 공식 Pretendard 배포본에서 받아, 지금 있는 Regular·Bold와 같은 형식(OTF)으로 `assets/fonts`에 넣는다.
2. **세로 탭 글자:** 처음 정한 세워 쌓기 대신 이전처럼 눕힌 글자로 되돌렸다. **이유:** 세워 쌓으면 높이 112에 글자가 4~5자만 보여, 실제 제목 대부분이 잘렸다(폭 48에서 21자 보이던 30자 제목이 4자만 보임). 제목이 보이는 것이 모양보다 중요하다. 규칙은 4.1을 따르고, 바를 넓히면 줄이 늘어난다.
3. **"모두 접기" 단추:** 기능은 지금의 "잠깐 숨기기" 그대로 두고 이름만 정리한다.
4. **바 폭:** 설정 범위(24~100)와 저장값은 그대로 둔다. 바의 단추·손잡이 폭은 바 폭을 따르고, 높이만 규격(단추 32, 손잡이 40)대로 한다.
5. **날짜 팝업:** 달력으로 바꾸고 "넣기"는 `YYYY-MM-DD`로 넣는다. 날짜·시간 단축키 5개는 유지한다.
6. **제목순 정렬:** 제목순일 때만 방향 칩 문구를 "가나다순 / 역순"으로 쓴다.
7. **AI 키워드 추출:** 없애지 않는다. 다섯 번째 칩 "키워드 뽑기"로 둔다.
8. **직접 만든 색의 우클릭 메뉴:** 지금 기능(색 편집·삭제)을 유지하고 문구만 "색 바꾸기 / 지우기"로 쓴다.

11. **대화창:** OS 제목 표시줄을 유지하고 창 안쪽만 이 문서대로 한다. 어두운 화면에서는 Windows 제목 표시줄도 어둡게 한다. `QMessageBox`는 QSS로 다듬고 단추 문구만 이 문서대로 바꾼다. (4.6·4.7의 둥근 창 바깥 모양과 `shadow_xl`보다 이 결정이 우선한다.)
    같은 제목이 두 번 보이지 않게 창 종류에 따라 나눈다. 닫기 단추는 OS 것만 둔다.
    - 설정 창: OS 제목 표시줄에 "설정". 창 안의 머리는 없애고 탭부터 시작한다.
    - 확인·알림 대화창: OS 제목 표시줄에는 "SlideMemo"만 둔다. 창 안 머리에는 제목 글자(`title` 18/28)로 묻는 문장을 쓴다. 예: "휴지통을 비울까요?"
12. **포커스 표시:** 두께는 그대로 두고 테두리 색만 바꾼다. 평소 테두리가 없는 부품은 투명한 1px 테두리를 깔아 두고 포커스 때 색만 넣는다. 자리가 밀리면 안 된다. (2.7의 "2px 테두리, 2px 띄움"보다 이 결정이 우선한다. 포커스 표시는 끄지 않는다.)
13. **글자 크기 단위:** 앱 화면(QSS)은 이 문서대로 px를 쓴다. 메모 본문 글자 크기는 지금처럼 pt로 두고 저장된 메모는 건드리지 않는다. 96dpi에서 16px는 12pt이므로 기본값은 12pt다. 글꼴 팝업도 pt로 보여 준다. 2.1의 "메모 본문 16px"도 12pt로 읽는다.
14. **새 링크 색:** 저장할 때 앱이 넣은 링크 색만 HTML에서 지우고, 불러올 때 다시 칠한다. Qt는 `setDefaultStyleSheet`로 칠한 색도 저장할 때 HTML에 넣기 때문이다. 이미 저장된 메모의 인라인 링크 색은 그대로 둔다.
15. **텍스트 선택 색:** 두 화면 모두 `#5055B1` 위에 흰 글자로 한다.
16. **형광펜을 칠한 글자:** 9번의 형광펜 5색은 어두운 화면에서 짝이 되는 값으로 바꿔 칠한다. 목록에 없는 예전 배경색이 칠해진 글자는, 글자색이 따로 없으면 불러올 때만 `#1B1D22`와 `#FFFFFF` 중 배경과 대비가 더 큰 쪽으로 칠하고 저장할 때 지운다. 메모 파일 내용은 바꾸지 않는다.
17. **검색어 강조:** 본문에 `ExtraSelection`으로 표시해 저장되지 않게 한다. 모양은 `highlight` 면에 `#1B1D22` 글자다.
18. **기존 메모 색 옮기기:** 이름이 아니라 실제 색의 색상(hue)으로 가장 가까운 종이 톤 프리셋으로 옮긴다. 회색으로는 채도가 거의 없는 색만 보낸다. 기준은 OKLCH 채도 C < 0.01이다(3.0.2의 C < 0.03보다 이 결정이 우선한다). 그라데이션을 쓰던 메모는 첫 번째 색을 기준으로 옮기고, 그라데이션 프리셋 자리는 없앤다. 옮긴 결과는 처음 켤 때 3.0.2대로 안내한다.
19. **검색어 강조 색:** 노란 형광펜(`#FFDD95`)과 구분되도록 `highlight`를 `#FFB870`으로 바꾼다. 글자는 `#1B1D22`, 두 화면 모드에서 같은 값이다(대비 9.91:1). 1장 `highlight` 토큰과 끝의 대비표를 함께 고쳤다. 형광펜 노랑은 9번 표 그대로다.
20. **(폐기: 27번으로 배너가 없어짐) 클립보드 배너 단추:** 실제 동작이 새 메모를 만드는 것이라 "새 메모로 붙여넣기"로 쓴다(4.2의 "붙여넣기"보다 이 결정이 우선한다).
21. **목록에 없는 예전 글자색:** 불러올 때만 보정하고 저장은 원래 값 그대로다. 두 화면 모드 모두 적용한다. 채도 C < 0.01인 회색·검정·흰색은 `ink`로 보여 주고, 색이 있는 것은 색상(hue)을 두고 메모 면과 4.5:1이 될 때까지 밝기만 옮긴다. 밝은 화면은 종이 톤 중 가장 어두운 회색 면을 기준으로 계산해 어느 메모에서나 기준을 넘는다. 자체 배경색이 있는 글자와 링크는 보정하지 않는다.
22. **세로 탭:** 4.1의 모양을 따른다. 열린 탭은 메모 면 색으로 칠하고, 창과 닿는 안쪽은 테두리 없이 직각이다. 제목 없는 탭은 괄호 없이 "제목 없음"을 `fg_secondary`로 보여 준다. 글자 규칙은 2번과 4.1을 따른다.
23. **토스트:** 검색 칸과 정렬을 덮지 않게 서식바 바로 아래에 띄운다(4.2의 "창 위쪽 가운데"보다 이 결정이 우선한다). 마우스를 올리고 있는 동안은 4초 타이머를 멈춘다.
24. **바 스크롤:** 띠가 모니터 끝에 닿도록 스크롤 막대를 숨긴다. 위나 아래에 탭이 더 있을 때만 그쪽 끝에 셰브런 단추(24)를 보여 주고, 누르면 탭 하나만큼 움직인다. 메모를 펼치면 그 탭이 보이는 위치로 스크롤한다.
25. **제한: 화면 모드와 Ctrl+Z.** 화면 모드가 실제로 바뀌면 메모 문서를 다시 만들어서 Ctrl+Z 기록이 비워진다. 같은 모드로 다시 저장할 때는 지우지 않는다. 메모 내용과 이전 버전은 영향을 받지 않는다.
26. **(폐기: 27번으로 배너가 없어짐) 좁은 창의 클립보드 배너:** 미리보기 글을 알아볼 수 없을 만큼 좁으면 글을 빼고 아이콘, "새 메모로 붙여넣기", 닫기만 보여 준다.
27. **클립보드 배너 제거:** 메모를 펼칠 때 클립보드를 확인하던 배너와 설정 체크박스를 없앤다("기능을 없애지 않는다"의 예외). 예전에 저장된 `clipboard_capture_enabled` 값은 읽지 않고 무시한다.
28. **바 아래 묶음 순서:** 위에서부터 새 메모 → 휴지통 → 숨기기(»)다. 새 메모는 가장 자주 쓰니 탭 목록 바로 아래에, 숨기기는 잘못 누르지 않게 맨 끝에 둔다.
29. **휴지통 아이콘과 툴팁:** 숫자 배지는 유지하고, 툴팁은 개수를 문장으로 알린다. 아이콘은 비어 있어도 둔다.
30. **고정 탭 표시:** 핀 아이콘을 빼고 띠 색 책갈피 리본(폭 10, 길이 14, 끝 V 4px)을 탭의 읽기 시작 쪽 끝에 띠와 4px 띄워 둔다. 띠와 같은 색이라 붙이면 한 덩어리로 보인다. 열린 탭, 접힌 바, 좌우 모두 같고 왼쪽 붙음이면 좌우가 뒤집힌다. 글자 자리는 고정하지 않은 탭과 같다. 툴팁은 "제목 · 고정됨"이고 제목이 다 보여도 띄운다.
31. **가이드 단계:** 바 단계는 아래 묶음 순서(새 메모 → 휴지통 → 숨기기)를 따라간다. 가이드는 예약을 하나로 모아 한 번에 말풍선 하나만 띄운다.

| 번호 | 가리키는 곳 | 제목 | 설명 |
|---|---|---|---|
| 바 1 | 첫 탭 | 탭을 눌러 메모를 펼쳐요 | 한 번 더 누르거나 Esc를 누르면 접혀요. |
| 바 2 | 새 메모(+) | 새 메모를 만들어요 | 탭 아래 더하기 단추를 누르거나 Ctrl+N을 눌러요. |
| 바 3 | 휴지통 | 지운 메모는 휴지통에 있어요 | 여기서 다시 꺼내거나 완전히 지울 수 있어요. |
| 바 4 | 손잡이 | 바를 옮기고 크기를 바꿔요 | 손잡이를 끌면 위아래로 옮겨요. 바 안쪽 가장자리를 끌면 폭이, 위아래 끝을 끌면 길이가 바뀌어요. |
| 바 5 | 숨기기(») | 바를 잠깐 숨겨요 | Ctrl+Shift+Z로도 숨길 수 있어요. 남은 로고 단추를 누르면 다시 나와요. 설정은 바를 우클릭해서 열어요. |
| 본문 1 | 제목 칸 | 저절로 저장돼요 | 바로 저장하고 싶으면 Ctrl+S를 눌러요. |
| 본문 2 | 서식바 | 글자를 꾸며요 | 굵게(Ctrl+B), 기울임, 색, 목록, 표를 쓸 수 있어요. |
| 본문 3 | 색 단추 | 메모 색을 바꿔요 | 제목 옆 색 단추로 고르거나 나만의 색을 만들어요. |
| 본문 4 | 검색 칸 | 찾고 정리해요 | 검색(Ctrl+F), 정렬, 고정, 내보내기는 맨 위 줄에 있어요. |

32. **처음 켤 때 안내 창은 하나만:** 업데이트 안내가 뜨는 경우에는 메모 색 안내 창(3.0.2)을 따로 띄우지 않는다. 업데이트 안내의 메모 색 줄이 그 역할을 한다. 새로 설치한 사용자는 옮길 메모가 없어 둘 다 뜨지 않는다.
33. **버전 2.0.0:** 이번 개편은 2.0.0으로 낸다. 로고와 화면이 통째로 바뀌었고, 클립보드 배너가 빠졌고, 메모 색 옮기기는 1.x로 되돌릴 수 없기 때문이다. 되돌리려면 옮기기 전에 만든 `memos.db.bak`을 쓴다.
34. **처음 실행 안내 창:** 제목은 "화면 가장자리에 붙는 메모장이에요". 본문은 글머리표·굵은 글씨 없이 문단 두 개("탭을 누르면 메모가 펼쳐지고, 한 번 더 누르거나 Esc를 누르면 접혀요." / "사용법을 말풍선으로 짧게 알려 드릴까요? 언제든 건너뛸 수 있어요.")이고, 맨 아래에 `caption` `fg_secondary`로 "나중에 보려면 바를 우클릭해서 설정의 '사용법 다시 보기'를 눌러요."를 둔다. 단추는 "나중에" / "가이드 보기"이고 기본(Enter)은 "가이드 보기"다. 되돌릴 수 없는 일이 아니기 때문이다. 단계 수는 이 창에서 보여 주지 않는다.
35. **투명 창의 잔상과 클릭:** 반투명 창(말풍선·툴팁)은 보이는 채로 글자를 바꾸고 옮기면 이전 자리에 그림이 남아, 누를 수 없는 말풍선이 하나 더 보였다. 바꾸거나 옮길 때는 먼저 숨긴다. 툴팁은 누를 것이 없으니 `WindowTransparentForInput`으로 그림자 여백까지 클릭이 통과하게 한다. 가이드 말풍선이 떠 있는 동안 툴팁은 띄우지 않고, 앱이 비활성이 될 때·펼치거나 접을 때·가이드를 시작할 때 닫는다. 말풍선은 투명 여백이 바를 덮지 않게 바 바로 바깥에 붙이고(카드와 바 사이 간격 = 여백 12), 바를 옮기거나 크기를 바꾸면 따라간다. 메뉴·팝업은 열려 있는 동안 바깥을 누르면 닫히는 창이라 그대로 두고, 로고 단추는 여백이 안쪽 3px뿐이라 그대로 둔다. 토스트는 창 안의 부품이라 다른 창을 덮지 않는다.
36. **이름은 "SlideMemo" (2.1.0):** 앱 안(창 제목, 트레이 툴팁, 숨김 알림, 설정 정보 탭, Qt 앱 이름)과 설치 프로그램(제어판 표시 이름, 시작 메뉴·바탕화면 바로가기, 설치 끝 "실행" 문구)을 모두 붙여 쓴 "SlideMemo"로 통일한다.
    - **그대로 두는 것:** 설치 AppId(`{C0F7E1B2-…}`), 설치 폴더(`…\Programs\SlideMemo`), 자동 실행 Run 값 이름(`SlideMemo`), 메모 폴더(`.memo_slide`), keyring 이름(`memo_slide_ai`, `memo_slide_sync`), 작업 표시줄 식별자(AppUserModelID `anthropic.slidememo.app`). 작업 표시줄 식별자를 바꾸면 이미 작업 표시줄에 고정한 아이콘과 실행 중인 창이 따로 묶여 고정이 갈라지기 때문이다. AppId가 같아 업데이트해도 제어판 항목은 하나로 이어진다.
    - **옛것 정리:** 2.0.0까지의 시작 메뉴 폴더 "Slide Memo"를 다시 쓰지 않도록 `UsePreviousGroup=no`로 하고, `[InstallDelete]`로 옛 시작 메뉴 바로가기 두 개, 비었으면 옛 폴더, 바탕화면의 옛 바로가기를 지운다.


### 구현 방식에서 정한 것

- 6.1절 `memo_tokens`, `apply_memo`의 `stops` 인자는 그라데이션이 없어졌으므로 색 하나를 받는다.
- 탭·견본처럼 색이 제각각인 부품은 QPainter로 그려 `setStyleSheet` 두 곳 규칙을 지킨다.
- 6.1절의 hex 검사에서 `test_*.py`는 뺀다.
- UI 아이콘은 4.9의 Lucide 표를 따른다.
- 휴지통 배지는 `caption`이 아니라 12/500으로 맞춘다.
- 가이드 8단계의 제목·설명 문구는 구현하며 초안을 쓰고 4단계 보고 때 확인받는다.
